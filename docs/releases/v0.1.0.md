# Prezi v0.1.0

First desktop preview for Linux x64, Windows x64, macOS Apple Silicon and macOS Intel.

[Downloads](https://alexanderwanyoike.github.io/prezi/) · [Release assets and checksums](https://github.com/alexanderwanyoike/prezi/releases/tag/v0.1.0)

## Included

- Canvas text editing, media positioning, slide management and manual reveals.
- Tabbed Canvas and Code views, editable Remotion scenes, declared properties and programmable transitions.
- Portable `.prezi` archives containing presentation content, source, media, fonts and notices.
- Shared human and MCP editing with labelled Undo/Redo, including agent batches.
- Application menus, light/dark appearance, accents and saved presentation themes.
- Windowed and fullscreen presentation with held reveals and video playback.
- Explicit update download, verification and restart on installed Windows/Linux builds. macOS uses release downloads.

Recording uses external applications such as OBS. Playback and ordinary editing work locally.

## Installation

Choose the installer matching your operating system and architecture. Verify its SHA-256 against `SHA256SUMS` in the release assets.

- Linux: make the AppImage executable and run it. Custom scene compilation and validation require a user systemd session with delegated CPU, memory and process controllers on cgroup v2.
- Windows: run the per-user installer. This preview is unsigned.
- macOS: open the matching DMG and copy Prezi to Applications. These previews are ad-hoc signed and are not notarized.

## Preview limits

- Custom scenes have startup and heartbeat deadlines. A scene that exceeds them detaches with an error; the editor remains available for correction or Undo.
- Unsigned Windows installers and non-notarized macOS bundles can trigger operating-system trust prompts.
- Media import and custom scene execution have resource limits. Invalid imports and failed source validation preserve the working project.
