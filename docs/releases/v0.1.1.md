# Prezi v0.1.1

- Startup and New presentation create one empty slide without the Vibez demo or bundled example video.
- New decks use a neutral white-and-grey palette. Saved presentations keep their colours, and slide styling remains editable in View > Presentation theme.
- Fallback rail previews follow the deck's colours.
- Packaged Linux AppImages register a user-local application-menu entry and persistent icon. Starting a moved AppImage refreshes its managed entry. Registration failures leave the editor available.
- The website explains the editor, its workflows and its features.

[Downloads](https://alexanderwanyoike.github.io/prezi/) · [Release assets and checksums](https://github.com/alexanderwanyoike/prezi/releases/tag/v0.1.1)

Installed Linux AppImage and Windows users can choose View > Application updates, check for updates, download and restart. Unsaved work is protected and saved projects reopen after restart. macOS users can download the matching DMG from the release page.

Windows installers remain unsigned. macOS bundles remain ad-hoc signed and are not notarized. Verify downloaded files against SHA256SUMS.

The combined changes passed 121 unit tests, formatting, lint, strict types and the production build. Native feature checks passed on Linux x64, Windows x64 and both macOS architectures. Private-display verification covered blank/neutral startup, theme editing, portable and legacy projects, fullscreen, real AppImage menu registration/launch and the website's desktop/mobile light/dark layouts. The release pipeline repeats application and installed checks before publication.
