# Transition compilation

The transition function contract supports generated typed properties and Remotion interpolation without requiring a React component. Accepted source is evaluated in an isolated, muted renderer at 61 progress values for both roles and navigation directions. Numeric output bounds and stable endpoints are validated before one revision-guarded Undo action stores source, properties and samples.

The compiler test and real Electron/MCP journey passed on this branch. The journey checks forward/back samples, retrying an accepted request, a mid-transition exception preserving the working definition, and shared Undo/Redo. Build and strict type checking passed. Separate failing tests were committed before implementation.

Manually compiled a transition through the real SDK, inspected its source in the existing Code view and verified that the worker closed. The compiler reported a kernel-scoped peak of 172,244,992 bytes, a 1 GiB memory cap and zero swap. All desktop checks used private Xvfb displays and profiles. Playback and human authoring follow as separate dependent changes.
